# Игра «Жизнь»

Классическая «Жизнь» Конвея — единственное правило B3/S23 — на замкнутом поле.
Rust + egui: правило локальное и детерминированное, обновление синхронное, ядро
не зависит от UI. Поле замкнуто в тор — через край можно перейти (см. «Замкнутое
поле»).

![скриншот](docs/screenshot-placeholder.svg)

## Запуск

```bash
cargo run --release
```

Открывается окно 960×600; при старте сетка подгоняется под окно при клетке
14 px. Дальше мир меняется только при зуме — ресайзы окна картинку лишь
растягивают.

Проверки:

```bash
cargo test          # 83 теста: юниты, интеграция, property-тесты
cargo clippy --all-targets
cargo build --release
```

## Управление

| Действие | Как |
|---|---|
| Оживить клетку | ЛКМ |
| Убить клетку | ПКМ |
| Рисовать линией | перетаскивание ЛКМ или ПКМ |
| Масштаб (клетка 1..32 px) | Ctrl + колесо мыши |
| Пуск / Пауза / Шаг / Очистить | кнопки сверху |
| Случайное поле | число «Заполненность» + кнопка «Случайно» |
| Скорость | число «Поколений в секунду» (1..60) |
| Продолжить после Game Over | Пуск или Шаг |

В интерфейсе больше ничего нет: сверху — только то, без чего игра не
обходится, снизу — поколение, число живых клеток, размер поля, размер клетки и
сообщения. Заполненность и скорость задаются числовыми полями (`DragValue`):
их можно двигать мышью и вводить с клавиатуры, ползунков нет.
Симуляция анимируется сама: кадры запрашиваются повторно, пока игра
идёт, поэтому мышь может оставаться неподвижной. `Шаг` ставит игру на паузу и
делает ровно одно поколение, `Очистить` тоже ставит паузу и убивает все
клетки.

## Вид

Белая тема: панели чисто-белые, текст чёрный, поле белое с чёрными клетками.
Элементы управления крупнее стандартных egui — шрифт 16 px, увеличенные
отступы кнопок и числовые поля высотой 32 px (`apply_theme` в `src/app.rs`).

## Масштаб

Зум — **Ctrl + колесо мыши** (50 px прокрутки = один шаг). Размер клетки
крутится в пределах 1..32 px и одновременно меняет размер сетки: мир
пересчитывается через `grid_dims_for` под текущую область окна, старое
содержимое центрируется, лишнее по краям обрезается. Подгонка происходит
только при смене зума — ресайз окна мир не обрезает, картинка просто
растягивается. Обычное колесо без Ctrl масштаб не меняет.

## Правило

Одно поколение — синхронный переход по N8-соседству: все клетки читают старое
состояние и пишут в буфер `next`, который подменяет сетку атомарно.

- живая клетка выживает при **2 или 3** живых соседях (**S23**);
- мёртвая клетка рождается ровно при **3** живых соседях (**B3**);
- во всех остальных случаях клетка мертва.

Весь движок — `src/sim/life.rs`: сетка, счётчик поколений и число живых клеток.
Поколение увеличивается даже на пустом поле. «Жив» = `CellState::Citizen` без
данных гражданина, тест — `Cell::is_alive`.

## Game Over

Поле конечно, поэтому мир обязан рано или поздно повториться — и повтор это
конец игры.

- Каждое поколение хэшируется и запоминается. Как только отпечаток уже
  встречался, игра встаёт на паузу, а в статус-баре появляется красная строка
  `Game Over: мир повторился, цикл N поколений`.
- Вымершая колония циклится на первом же шаге — строка другая:
  `Game Over: колония вымерла`.
- Дальше мир не развивается: `Life::cycle` помнит длину цикла, пока игрок не
  правит мир.
- **Продолжить:** `Пуск` или `Шаг` после Game Over сбрасывают историю и
  проигрывают тот же цикл заново — Game Over повторится ровно через длину
  цикла.
- **Начать заново:** любая правка клетки, `Очистить` или `Случайно` начинают
  новую историю, и красная строка гаснет сама.

## Замкнутое поле

Сетка — тор: левый край соединён с правым, верхний с нижним. Выход за край
возвращает клетку с противоположной стороны.

Заворот действует во всех подсчётах соседей:

- **Соседи N4 / N8.** У угловой клетки столько же соседей, сколько у любой
  другой, некоторые просто приходят «из-за края». Дубликатов нет: на поле из
  двух клеток левый и правый сосед — одна и та же клетка, и она считается один
  раз.
- **Радиусы** измеряются по тору и не обрезаются краем.
- **Рисование мышью** клетку за краем не достаёт — курсор физически не может
  выйти за canvas.

Глайдер, живущий поперёк шва, обходит всё поле и возвращается на исходную
клетку за полный оборот — это покрыто тестом.

При старте мир подгоняется под окно (`grid_dims_for`, клетка 14 px), а дальше —
при каждом изменении зума; ресайзы окна сетку не меняют. Любая смена размера
сетки центрирует старое содержимое и обрезает лишнее по краям.

## Палитра

| Состояние | RGB |
|---|---|
| Живая клетка (`palette::ALIVE`) | `#000000` |
| Поле, мёртвая клетка (`palette::FIELD`) | `#FFFFFF` |

Поле белое, живые клетки чёрные. Грани чёрные, фиксированной толщины 1 px:
на белом поле они дают тонкую сетку, а у чёрных клеток сливаются с заливкой.
При клетке в один пиксель граней нет вообще — места на рамку не остаётся.

## Устройство

- `src/sim/life.rs` — правило B3/S23, счётчики, заполнение, смена размера,
  история отпечатков для Game Over.
- `src/sim/grid.rs` — тор: `wrap`, `neighbors4` / `neighbors8`, `cells_in_radius`.
- `src/ui/canvas.rs` — текстура `ColorImage`, dirty-region, ввод мыши, зум
  Ctrl+колесом.
- `src/ui/panels.rs` — тулбар и статус-бар.
- `src/app.rs` — цикл кадра, бюджет тиков, кнопки, белая тема и размер шрифтов.

Бюджет тиков: не более 6 поколений за кадр, дробный остаток накапливается,
поэтому низкая скорость всё равно продвигает игру.

## Старый код

Колония из исходного ТЗ — ресурсы, стресс, конструкции, антиклетки — осталась в
репозитории как справочный код и в игру не вызывается: её модули в `src/sim/`,
старые тесты в `tests/simulation.rs` и `tests/properties.rs`, палитра и
`SimConfig`. Из интерфейса она убрана полностью. Правило «Жизни» от них не
зависит, но эти тесты обязаны оставаться зелёными.

## Производительность

- Сетка — плоский `Vec<Cell>`; буфер `next` клонируется один раз на поколение.
- Не более 6 поколений за кадр; дробный остаток накапливается.
- Отрисовка идёт одной `ColorImage` через `TextureHandle`; перерисовывается
  только bounding box изменившихся клеток, поэтому пауза не ест GPU.
- Сторона текстуры ограничена 2048 px — пределом GPU; `grid_dims_for` держит
  сетку в этих пределах при любом зуме.

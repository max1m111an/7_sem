## Задание 1. Переменные и типы данных

В ходе выполнения задания изучены переменные и типы данных языка. Объявлены константа `firstName` (строка) и переменная `age` (число), для проверки типов использован оператор `typeof`, также объявлена переменная `isActive` типа `boolean`. Рассмотрено отличие `let` (переобъявляемая) от `const` (неизменяемая ссылка). Применена проверка поведения переменной без значения (даёт `undefined`) и переменной со значением `null`.

Применена функция `getType()`, которая определяет реальный тип значения: для массивов возвращает `"array"`, для `null` – `"null"`, для остальных – результат обычного `typeof`. Проверили результат выражения `typeof typeof 4`.
